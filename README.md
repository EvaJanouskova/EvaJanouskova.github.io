# Eva Janoušková – Personal Website

Welcome to the source code repository for my personal academic and professional website.

**Live Site:** [https://evajanouskova.github.io](https://evajanouskova.github.io)

* **Framework:** [Jekyll](https://jekyllrb.com/) using the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template
* **Hosting:** GitHub Pages
* **Formatting:** British English (`en-GB`)

## Repository Structure
* `_config.yml` – Main Jekyll site configuration
* `_data/navigation.yml` – Header menu bar links
* `_pages/` – Core site pages (`about.md`, `cv.md`, `publications.md`, ...)
